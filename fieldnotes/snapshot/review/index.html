Each NN-…/REVIEW.md → concept, workshop role, screen-by-screen intent, what is factual vs hypothetical, known issues, screenshot filenames. 5. iteration-001/BUILD_REPORT.md → what changed and what is unresolved.

A limitation of this fallback, stated plainly

Google Drive is not reachable from the session that produced this bundle, so it is served as a static route. That makes it readable by another session but not writable: a reviewer cannot save reviews/iteration-001-review.md back here. Those two files have to be carried to the next build session by the human in the loop. With Drive, the loop closes by itself; here it does not.
